🛒 Proyecto Final - Ecommerce de Electrónica

Descripción

Este proyecto es un simulador de tienda online desarrollado con **HTML, CSS y JavaScript puro**, como parte de un trabajo final del curso de programación en JavaScript.

La aplicación permite visualizar productos electrónicos obtenidos desde una API externa, agregarlos a un carrito de compras, gestionarlos dinámicamente y simular el proceso completo de compra.

---

Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- LocalStorage
- Async / Await
- Manipulación del DOM

---

API utilizada

Se utilizó la siguiente API pública para obtener productos:

https://fakestoreapi.com/products

Se filtran únicamente productos de la categoría **electronics**.

---

Funcionalidades principales

- Listado dinámico de productos desde API
- Filtrado por categoría (electronics)
- Agregar productos al carrito
- Eliminar productos del carrito
- Cálculo automático del total
- Persistencia del carrito con LocalStorage
- Simulación de compra
- Mensajes de interacción en pantalla (sin alert)
